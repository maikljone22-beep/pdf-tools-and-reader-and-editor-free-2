# Foxit PDF Editor vs SmartDocs: sections 28–33 and 35–42

This compares the Foxit inventory (`scratchpad\foxit\FOXIT_FEATURES.md`, sections 28–33 and 35–42; section 34 is covered elsewhere) with SmartDocs **main** at commit `3a1c44a` in `D:\pdf\SmartDocs-project-v0.4.0`. The work was read-only.

**Paths.** Evidence paths are relative to `app/src/main/java/com/smartdocs/editor/`. Strings are in `res/values-en/` (English) and `res/values/` (Arabic).

**Reused rows.** Rows that match a Nitro row reuse that row's status, marked "see cmp_09-15" and so on. Those rows were re-checked against `gaps/verify_B.md`. Rows with extra Foxit options were checked again in the code.

**Branches.** Work on `feature/nitro-protect`, `feature/nitro-protect-sign`, `feature/nitro-quicksign` and `feature/nitro-tools` is not counted. Only main is.

**Corrections to the Nitro comparison (found on main now):**
- Sanitize has dedicated SEARCH_INDEX, STRUCTURE and CROPPED items (`core/redact/Sanitizer.kt:19-21`; `ui/security/SanitizeScreen.kt:144-147`). cmp_09-15 listed "embedded search index" and "document structure" as PARTIAL.
- A pending-redaction banner exists in the reader (`ui/reader/ReaderScreen.kt:300` RedactMarksBanner). cmp_09-15 marked it PARTIAL.

Column "Nitro?": **yes cmp_xx** means the same gap or feature is already in a Nitro comparison file; **no** means it is new.
