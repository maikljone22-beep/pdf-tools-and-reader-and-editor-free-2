# Reader tabs audit: TOOLS + PAGES (read-only)

Base: D:\pdf\SmartDocs-project-v0.4.0 (paths below are relative to `app/src/main/java/com/smartdocs/editor/`).
How I checked: I read the code myself for ReaderToolbars, ReaderScreen, QuickController/Actions/Sheets, OrganizeScreen/State/PageGrid, ReaderPanels thumbnails, PdfOps, ReaderGuard, ReaderRestrictions, the AccessibilityScreen and PdfAScreen, and NveOrganizeInsertMore. Four read-only sub-audits covered the deeper tool screens: (a) redact/sanitize/protect, (b) the OCR suite, (c) compare/convert/AI/search/merge/split/forms, (d) the edit5 page tools. The PdfBox behaviour was checked by running it on the JVM (section 3).

Strings: I checked all 981 `R.string` ids used by the Tools/Pages files (ReaderToolbars, pages/*, quick/*, Edit5Hub, nve/shell/*, Accessibility, PdfA, print, share5). Every one exists in `values` (Arabic is the default) and in `values-en`. There is no `values-ar` folder; Arabic is the base locale.
