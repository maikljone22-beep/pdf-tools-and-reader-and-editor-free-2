Read-only comparison against the `main` source in `D:\pdf\SmartDocs-project-v0.4.0`. Code paths are relative to `app/src/main/java/com/smartdocs/editor/`. Strings: `res/values/` holds Arabic (the default locale) and `res/values-en/` holds English. MODULE_*.md notes were used only as hints. Every status was checked against real UI callers.

Main UI entry points used as evidence:
- **Tools tab:** `ui/tools/ToolsScreen.kt:39-95`, routed by `ui/tools/ToolScreens.kt:30-100`.
- **Edit5 hub:** card `e5_hub` at `ToolsScreen.kt:93`, leading to `ui/edit5/Edit5Hub.kt:26-92`.
- **Reader tab toolbars:** `ui/reader/ReaderToolbars.kt`. The View tab is at :112-136, Edit at :174-188 and Tools at :248-298.
- **Reader overflow (⋮) menu:** `ui/reader/ReaderScreen.kt:224-243`, plus `ui/view5/View5Host.kt:102-110`.
- **View5 chips:** `ui/view5/View5Host.kt:66-98`.
