# خادم المراجعة المشتركة (التعليق معاً)

عامل Cloudflare صغير يحفظ ملف PDF المشترك وتعليقات كل مشارك، ويقدّم صفحة رابط المشاركة.
التطبيق يستخدمه من شاشة "مراجعة مشتركة" (المسار `review`) ومن الرابط العميق `smartdocs://review/<id>?c=<code>`.

## النشر (مرة واحدة، مجاناً)
1. `npm install -g wrangler` ثم `wrangler login`.
2. من هذا المجلد: `wrangler kv namespace create COLLAB` وانسخ المعرّف إلى `wrangler.toml`.
3. (اختياري) `wrangler r2 bucket create smartdocs-reviews` ثم أزل التعليق عن قسم `r2_buckets` — لملفات أكبر ولتوفير مساحة KV.
4. (اختياري لكن مُستحسن) `wrangler secret put APP_TOKEN` — كلمة سر طويلة تُرسَل من التطبيق مع كل طلب.
5. `wrangler deploy` ← ستحصل على عنوان مثل `https://smartdocs-collab.<name>.workers.dev`.
6. في جذر مشروع التطبيق أضف إلى `cloud.properties`:
   ```
   collabUrl=https://smartdocs-collab.<name>.workers.dev
   collabToken=<نفس APP_TOKEN أو اتركه فارغاً>
   ```
7. أعد بناء التطبيق. زر "مراجعة مشتركة" يصبح فعّالاً (معطّل ما دام `collabUrl` فارغاً).

## كيف يعمل
- المالك يرفع PDF ← يحصل على معرّف (10 أحرف) + رمز دخول (6 أحرف) + رابط مشاركة `https://…/r/<id>?c=<code>`.
- كل مشارك يكتب في مفتاح KV خاص به (`comments:<id>:<participant>`) فلا يمحو أحدٌ تعليقات غيره.
- التطبيق يرسل تعليقاته عند كل حفظ ويجلب تعليقات الآخرين كل 30 ثانية ما دامت شاشة المراجعة مفتوحة.
- كل تعليق = قاموس PDF الخاص به بصيغة JSON (نفس معلومات XFDF + مظهر التعليق)، ويُدمج حسب المعرّف `/NM`.
- بعد الموعد النهائي أو الإغلاق: القراءة فقط (الإرسال يُرفض برمز 410). تُحذف المراجعة تلقائياً بعد 30 يوماً من الموعد النهائي، أو 90 يوماً إن لم يُحدَّد موعد.

## المسار `/oauth/<provider>`
إن رفض Dropbox أو OneDrive عنوان إعادة التوجيه `smartdocs://oauth/…` فسجّل بدلاً منه
`https://smartdocs-collab.<name>.workers.dev/oauth/dropbox` (أو onedrive) في لوحة المزوّد، وضعه في `cloud.properties`
(`dropboxRedirect=` / `onedriveRedirect=`). العامل يعيد التوجيه إلى التطبيق مع نفس المعاملات.

## الحدود الصريحة
- لا حسابات: من يملك الرابط والرمز يستطيع القراءة والتعليق. لا تشارك مستندات سرية بهذه الطريقة.
- KV متسق نهائياً: قد يتأخر ظهور تعليق جديد حتى ~60 ثانية في مناطق أخرى.
- لا إشعارات فورية (استطلاع كل 30 ثانية).
- حد الملف 20MB.
