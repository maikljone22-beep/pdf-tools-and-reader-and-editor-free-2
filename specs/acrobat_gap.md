# SmartDocs vs Adobe Acrobat (Reader/Pro mobile, Acrobat Studio, desktop tools feasible on phone/tablet) and Adobe Scan: gap list

Date: 2026-10-25. Scope: only features that are **missing** or **partial** in SmartDocs. Features we already have in full are left out. Examples: view modes, crop view, tabs, page colours, auto-flip, markup, ink, shapes, polygon/cloud, caret/replace, stamps, attachments, sound/video annots, multi-select, comment threads/status, XFDF/FDF, comment summary, handwriting→text, content edit of text and images, outline editor, organize, merge, split by N/bookmarks/size, compress, watermark (text), page numbers, protect/unlock, certificate encryption, digital signing with TSA/LTV, templates, forms fill with AF calc, XFA data, OCR searchable and editable, PDF→Word/Excel/PPT/HTML/TXT/images, cloud (Drive/OneDrive/Dropbox), sync, Wi‑Fi transfer, shared review (basic), AI chat, AI doc agent (22 commands), AI voices, podcast/audio summary.

**Sources**
- Our side:
  - `/home/claude/smartdocs/MODULE_*.md`
  - code under `app/src/main/java/com/smartdocs/editor/`, checked with grep. Items marked "verified in code" were checked directly.
- Acrobat side:
  - helpx.adobe.com mobile pages (AI features, summaries, AI Assistant, voice commands, podcasts, Liquid Mode, crop pages, edit scanned files, draw / snap to shape, request e‑signatures, Student Spaces study tools, mobile release notes up to Aug 2026)
  - Acrobat desktop pages (redact, sanitize, edit via AI chat, auto-fill)
  - Adobe Scan for Android docs and release notes (up to Apr 2026)
  - long-standing Acrobat Pro desktop tool behaviour

**Legend**
- Difficulty: S ≤ 3 days · M ≈ 1–2 weeks · L > 2 weeks (one developer, our stack).
- Priority:
  - P1: must-have for parity, or core to our users (Arabic students and offices).
  - P2: important.
  - P3: nice to have / niche.
- "Proxy" = our Cloudflare Worker AI proxy (OpenAI-compatible; it already has `/chat/completions`, `/audio/speech`, `/audio/voices`).
