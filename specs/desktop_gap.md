# SmartDocs vs the desktop reference editor (Windows, Pro edition, 2025–2026 releases incl. AI Assistant): gap list

Date: 2026-10-25. Scope: only features that are **missing** or **partial** in SmartDocs. Things we already have in full are left out. That includes view modes, page colours, auto-flip, crop view, tabs, markup, ink, shapes, polygon/cloud, caret/replace, multi-select/grouping, XFDF/FDF, handwriting recognition, scanner, OCR (searchable and editable), PDF→DOCX/XLSX/PPTX/HTML/TXT/images, templates, certificate encryption, PAdES/TSA/LTV signing, podcast/AI voices and the 22-command document agent.

**Sources**
- Desktop side:
  - the reference editor's Windows user manual (495 pages, ©2001-2025 edition): every chapter, Preferences, keyboard shortcuts and print dialog;
  - its AI Assistant user manual (2026 edition: AI Chat, generation modes, skills, connectors, translate document, read aloud, smart podcast, AI bookmark, AI settings, formula recognition, workspace);
  - release notes for 2025.3 (Dec 2025), 2026.1 (Mar 2026) and 2026.2 (Sep 2026).
  The latest Windows build is 2026.2.1 (23 Sep 2026).
- Our side:
  - `/home/claude/featurespecs/*.md`, an analysis of the same vendor's Android app, which we cloned;
  - every `/home/claude/smartdocs/MODULE_*.md`;
  - `app/src/main/java/com/smartdocs/editor/**`, checked with grep. Rows marked "(code)" were checked directly in the code.

**Legend**
- **Diff:**
  - S: ≤ 3 days.
  - M: about 1–2 weeks.
  - L: more than 2 weeks, for one developer on our stack.
  - "—": not feasible.
- **Pri:**
  - P1: needed for parity, or core to our users (Arabic-first students, teachers and offices).
  - P2: important.
  - P3: nice to have or niche.
  - "—": not feasible or not applicable.
- **Stack:**
  - Kotlin/Compose (M3).
  - PdfBox-Android 2.0.27 (= "PdfBox"), which is our writer.
  - PDFium (`PdfSession`), which is our renderer and text/search engine.
  - Tesseract 4 for OCR, and the ML Kit document scanner / digital ink.
  - BouncyCastle 1.72.
  - The Cloudflare Workers "proxy" (`ai-proxy/`: `/chat/completions`, `/audio/speech`, `/audio/voices`, collab, license and esign workers) is OpenAI-compatible.
  - No new Gradle dependencies unless a row says so.
- **One-step UX rule** (from MODULE_quick): inside the reader a tool opens a compact sheet with its defaults already set and one primary button. The result replaces the open document in place, and the "تم" bar offers تراجع / حفظ كنسخة. Multi-file or authoring tools live in full screens reachable from the Tools tab.
- Arabic UI labels are suggestions (the desktop has no Arabic UI before 2026.2).
